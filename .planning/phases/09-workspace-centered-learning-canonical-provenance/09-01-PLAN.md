<name>Task 1: Define checksum contract and test it</name>
<files>src/lib/provenance/checksum.ts, src/lib/provenance/checksum.test.ts</files>
<behavior>
- Equivalent LF, CRLF, and CR canonical markdown yields one lowercase SHA-256 digest.
- Whitespace is not trimmed or otherwise rewritten.
- `canonical_content_checksum` hashes UTF-8 normalized canonical markdown only; provenance never changes it.
- `sections_checksum` hashes deterministic JSON tuples in fixed `{ordinal, section_key, heading, section_type, body_markdown}` field order after normalizing every string's line endings.
- Ordered section serialization changes digest when ordinal, heading, type, key, or body changes.
</behavior>
<action>Create pure Node `crypto.createHash("sha256")` utility. Export `checksumCanonicalMarkdown` as SHA-256 of UTF-8 markdown after only CRLF/CR-to-LF normalization, with no trim. Export `checksumSections` as SHA-256 of deterministic `JSON.stringify` over ordered tuples whose keys are inserted in fixed `ordinal`, `section_key`, `heading`, `section_type`, `body_markdown` order; normalize line endings in every string field before serialization. Exclude model/prompt/parser/settings/provenance from both digests. No custom crypto or provenance secrets.</action>
