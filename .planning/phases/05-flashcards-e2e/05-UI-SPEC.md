# Phase 5 — UI Design Contract

> Visual and interaction contract for **Flashcards pipeline & E2E** — enable Flashcards mode on canonical preview, three-step setup wizard, generation progress, flashcard learning session wiring, dashboard re-entry, and mistakes-only quiz drill. Generated by gsd-ui-researcher. **Extend Phase 4** — do not redesign dashboard shell, canonical preview chrome, quiz-play stitch theme, or flashcard flip canvas.

**Impeccable register:** `product` (instrument-like study workbench; calm, precise; earned familiarity over decoration; inline/progressive flows over modals).

---

## Phase Scope

| In scope | Out of scope |
|----------|--------------|
| Enable **Flashcards** CTA on `/sets/[id]/source` (replace disabled placeholder) | Pre-save quality validation gate (OOS-03) |
| Three-step wizard: goal → coverage → amount (FLASH-01–03) | Full flashcard review/edit workspace polish |
| Flashcard generation UX during `POST /api/study-sets/[id]/flashcards/generate` | Sharing, publishing, BYOK AI |

| E2E milestone verification (`next build`, vitest) — no new UI | |

**Upstream decisions used:** D-01–21 (`05-CONTEXT.md`), FLASH-01–07, CORE-MIST-01, MODE-01 Flashcards path (`.planning/REQUIREMENTS.md`), `04-UI-SPEC.md`, `03-UI-SPEC.md`, `DESIGN.md`, `PRODUCT.md`, `docs/pipeline.md`.

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn |
| Preset | `b2fA` — base-nova, neutral, lucide (`npx shadcn info`) |

**Identity rule:** Reuse Phase 3–4 canonical preview chrome, `QuizGenerateProgressCard` / `IngestProgressCard` progress vocabulary, `CanonicalModeSelectionFooter` layout, flat ledger cards (`rounded-xl ring-1 ring-foreground/10 bg-card/60`), oxblood primary buttons, chart-2 back links. Flashcard play keeps scoped `[data-quiz-play-theme="stitch"]` tokens — do not leak stitch colors into wizard or library shells.

**Anti-slop (Phase 5):** No eyebrow on every wizard field, no new side-stripe accents beyond the **existing** generation progress card shell, no gradient text, no candy flashcard-app styling, no modal-first wizard (inline stepped panel on source page).

## Spacing Scale

Declared values (multiples of 4; source: `DESIGN.md`, carried from Phase 3–4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Chip gaps, icon gaps |
| sm | 8px | Compact inline spacing (`gap-2`) |
| md | 16px | Card padding (`p-4`), wizard option row gap |
| lg | 24px | Section spacing (`space-y-6`), wizard step gap |
| xl | 32px | Page section separation |
| 2xl | 48px | — |
| 3xl | 64px | Page bottom padding (`pb-16`) |

**Exceptions (unchanged from Phase 3–4):**
- Generation progress card left accent stripe: **6px** — reuse progress card shell only.
- TOC sidebar width: **240px** (`w-60`) on `lg+`.
- Markdown prose max-width: **72ch** (`max-w-[72ch]`).
- Wizard option touch targets: **44px** minimum height on radio/card selectors (`min-h-11`).

## Typography

**Contract limit:** 4 sizes, 2 weights (checker-compliant; same as Phase 3–4).

| Role | Size | Weight | Line Height | Class / utility |
|------|------|--------|-------------|-----------------|
| Body | 14px (`text-sm`) | 400 | 1.625 | Default Manrope — subcopy, stats, helper text |
| Label | 12px (`text-xs`) | 800 | 1.2 | `font-label` uppercase, `tracking-wide` — status, wizard step, dashboard CTAs |
| Heading | 24px (`text-2xl`) | 800 | 1.25 | `font-heading tracking-tight` — page H1, wizard step headline |
| Display | 30px (`text-3xl`) | 800 | 1.15 | Not used in Phase 5 surfaces — auth/hero only |

**Weights:** 400 (body) and 800 (label, heading) only. Normalize stray `font-bold` (700) / `font-semibold` (600) in touched files to **800** or **400**.

**Flashcard play (stitch theme):** Existing play-session typography stays scoped to `[data-quiz-play-theme="stitch"]` — do not refactor in Phase 5 except empty-state copy and `onDone` routing.

## Mode Selection — Interaction Spec

### Visibility

- Show when `pipeline_stage ≥ canonical` and UI is in `preview` state (no active quiz/flashcard generate).
- Hide when canonicalizing, wizard active, or generating.
- Quiz resume strip when `pipeline_stage === 'quiz'` && `approvedCount > 0`.
- Flashcards resume strip when `pipeline_stage === 'flashcards'` && `cardCount > 0`.

### Flashcards path (D-01, D-02, MODE-01)

1. User clicks **Flashcards**.
2. Client sets `content_kind = 'flashcards'`, `pipeline_stage = 'mode_selected'` (optimistic OK; server is source of truth).
3. Transition to wizard step 1; hide markdown + TOC.
4. User completes wizard → `POST /api/study-sets/[id]/flashcards/generate` with body per D-12.
5. On 2xx: show success line ≤1.5s or immediate redirect to `/flashcards/{id}`.
6. On error: show `FlashcardGenerateProgressCard` error state + **Try again**.

### Quiz path

Unchanged from Phase 4. When `pipeline_stage === 'flashcards'`, do not show Quiz resume strip (mode-specific strips).
