# Phase 3 — UI Design Contract

> Visual and interaction contract for **Canonical Knowledge preview** at `/sets/[id]/source`. Generated by gsd-ui-researcher. Identity preservation wins — calm read-only workbench; do not redesign dashboard, import flows, quiz play, or flashcard session surfaces.

**Impeccable register:** `product` (instrument-like study workbench; calm, precise; document-first ledger aesthetic).

## Spacing Scale

Declared values (multiples of 4; source: `DESIGN.md`):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Chip gaps, icon gaps |
| sm | 8px | Compact inline spacing (`gap-2`) |
| md | 16px | Card padding (`p-4`), metadata row gap |
| lg | 24px | Section spacing (`space-y-6`), header block gap |
| xl | 32px | Page section separation |
| 2xl | 48px | — (not required Phase 3) |
| 3xl | 64px | Page bottom padding (`pb-16`) |

**Exceptions:**
- Canonicalize progress card left accent stripe: **6px** (`border-l-[6px]`) — matches Phase 2 ingest progress signature; preserve.
- TOC sidebar width: **240px** (`w-60`) on `lg+` — instrument panel width; not on 4px scale but consistent with review sidebars.
- Markdown prose max-width: **72ch** (`max-w-[72ch]`) — DESIGN.md body line-length cap.

## Typography

**Contract limit:** 4 sizes, 2 weights (checker-compliant).

| Role | Size | Weight | Line Height | Class / utility |
|------|------|--------|-------------|-----------------|
| Body | 14px (`text-sm`) | 400 | 1.625 | Default Manrope — subcopy, prose body, chip values |
| Label | 12px (`text-xs`) | 800 | 1.2 | `font-label` uppercase, `tracking-wide` — metadata eyebrows, TOC header, progress eyebrow |
| Heading | 24px (`text-2xl`) | 800 | 1.25 | `font-heading tracking-tight` — page H1 |
| Display | 30px (`text-3xl`) | 800 | 1.15 | Not used on this page — reserve for auth/hero only |

**Weights:** 400 (body) and 800 (label, heading) only. Normalize any stray `font-bold` (700) or `font-semibold` (600) in new components to **800** for headings/labels or **400** for body.

**Prose (markdown viewer):** Rendered markdown uses **body tier only** (14px / 400). Heading elements inside prose map to existing semantic sizes without adding a fifth tier:

| Markdown element | Rendered size | Weight |
|------------------|---------------|--------|
| `h1`–`h3` in source | 24px (`text-2xl`) | 800 |
| `h4`–`h6` | 14px (`text-sm`) | 800 |
| `p`, `li`, `td` | 14px (`text-sm`) | 400 |
| `code` (inline) | 14px (`text-sm`) | 400, `font-mono` |
| `pre` | 14px (`text-sm`) | 400, `font-mono` |

`font-mono` is a family switch only — not an additional size step.

## Color

60 / 30 / 10 split on canonical preview surfaces (light mode primary target):

| Role | Token / hex | Usage |
|------|-------------|-------|
| Dominant (60%) | `--background` `#f7faf8` (Mint Paper) | Page canvas via AppShell `d2q-technical-grid` |

| Accent (10%) | `--primary` `#5f0f00` (Oxblood), `--ring` `#ff967d` (Coral), `--chart-2` `#376757` (Forest Sage) | See reserved list |

**Accent reserved for:**
- Disabled primary CTA fill (oxblood at `opacity-50` — still reads as primary, not decorative)
- Retry CTA on error (oxblood, enabled)
- Focus rings on TOC links and back link (`ring-ring/50` coral)

**Not accent:** page backgrounds, markdown card fill, metadata chip fills (use `outline` badge), body copy, error text (use destructive).

**Metadata chips:** `Badge variant="outline"` — forest/muted text on card white; **not** oxblood primary fill (reserve oxblood for CTAs).

| Element | Copy |
|---------|------|

### Empty / edge states

| Context | Heading | Body |
|---------|---------|------|
| Initial page load | — | `Loading…` (`role="status"`) |

| Scenario | Copy |
|----------|------|

| Network error | Toast: `Connection lost. Check your network and try again.` |
| GET canonical fetch failure | Inline alert: `Couldn't load canonical preview. Try refreshing the page.` |

## Canonical Markdown Viewer — Interaction Spec

### Rendering

- **Library:** Add `react-markdown` + `remark-gfm` (executor choice; no HTML raw pass-through).
- **Input:** `canonical_markdown` string from `GET /api/study-sets/[id]/canonical` (or equivalent).
- **Security:** Sanitize — no `rehype-raw`; links get `rel="noopener noreferrer"` + `target="_blank"`.
- **Math:** If `canonical_markdown` contains `$$` or `\(` delimiters, render via existing MathJax assets (`mathjax` dep). Scope to inline/block math only — do not block Phase 3 on full LaTeX parity; plain text fallback acceptable for unsupported formulas.
- **Tables:** GFM tables preserved (`remark-gfm`).
- **Interaction:** Read-only — no edit affordances, no text selection styling beyond browser default.

### Prose scope

Apply scoped class `d2q-prose` on viewer root (define in `globals.css` or co-located CSS module):

- `color: var(--foreground)`
- Headings: `font-heading`, weights per typography table
- Links: `text-chart-2 underline-offset-2 hover:underline`
- `pre` / `code`: `bg-muted rounded-lg`
- `table`: `border-collapse w-full text-sm`, cell borders `border-border`
- `max-w-[72ch]` on prose container
- `select-text` enabled (user may copy study content)

### Section anchors (when TOC visible)

- Each `canonical_sections` entry renders as `id="section-{ordinal}"` anchor in the DOM (either by splitting render per section or injecting heading ids).
- TOC click: `scrollIntoView({ behavior: 'smooth', block: 'start' })` with 80px offset for app chrome.
- Active TOC item: `text-chart-2 font-label` + `aria-current="true"`.

**TOC visibility rule:** Show TOC only when `sections.length >= 2`. For a single section, omit sidebar and mobile toggle — full-width markdown only.

## Canonicalize Trigger — Interaction Spec

### Auto-start (D-07, user scope)

On page mount after successful meta + canonical fetch:

1. If `pipelineStage === 'raw'` and `raw_markdown` is non-empty → immediately `POST /api/study-sets/[id]/canonicalize`.
2. Set UI to `canonicalizing`; disable navigation CTAs except Back.
3. On 2xx: refetch canonical payload; transition to `preview`.
4. On 4xx/5xx: transition to `canonicalizeError`; show `Try again`.

**Guard:** Use a ref (`canonicalizeStartedRef`) to prevent double POST on React strict-mode remount.

### Manual retry

`Try again` re-POSTs canonicalize with same guards. Label does not change during retry (`Building canonical knowledge…`).

### Idempotent re-run (D-07)

Not exposed as a primary action in happy path. `Rebuild canonical` appears only in empty-canonical edge state.

## Accessibility

- **WCAG 2.1 AA:** Muted subcopy uses `text-muted-foreground`; errors use `text-destructive` + message text.
- **Landmarks:** `<main>` content (from AppShell) contains `<article aria-label="Canonical knowledge preview">` around markdown viewer.
- **Progress:** `aria-live="polite"` on canonicalize headline; `role="status"` on loading text.
- **TOC:** `<nav aria-label="Document sections">`; active item `aria-current="true"`.
- **Disabled CTA:** `aria-disabled="true"` + `disabled` attribute; helper text associated via `aria-describedby`.
- **Keyboard:** Tab order: Back → TOC toggle (mobile) → TOC links → markdown (scrollable) → footer CTA.
- **Touch targets:** Buttons ≥ 32px height (`h-8` default).
