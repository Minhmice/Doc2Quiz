| Ingest → MarkItDown | File bytes and YouTube URLs after validation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Elevation | file_ref storagePath | mitigate | Reject paths not matching `^${userId}/${studySetId}/` before download |
| T-02-07 | Spoofing | YouTube URL field | mitigate | validateYoutubeUrl before convertUrlWithMarkItDown (host allowlist, https only) |
| T-02-08 | Denial of Service | multipart upload | mitigate | validateFileUpload size before buffering; prefer file_ref for large files |
| T-02-09 | Tampering | canonical_documents upsert | mitigate | RLS + verifyStudySet ownership; user_id from auth token not client body |
| T-02-10 | Information Disclosure | ingest success response | mitigate | Return rawMarkdownLength only, not full markdown body |
| T-02-11 | Tampering | conversion failure state | mitigate | D-06: metadata.conversion_status failed; pipeline_stage stays pre-raw |
</threat_model>
