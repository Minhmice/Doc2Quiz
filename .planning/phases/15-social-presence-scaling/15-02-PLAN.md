<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser to friends/typing routes | Untrusted query, body, and conversation ID enter authenticated server handlers. |
| Auth service to relationship checks | Durable relationship state controls access before ephemeral Redis. |
| Server to Redis | User/conversation keys and typing state are server-generated. |
| Migration/RPC to SQL | Worker/application credentials cross into durable activity procedures. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-15-06 | Spoofing | friends/typing user identity | mitigate | Use `requireApiUser` and durable participant/accepted-friend checks. |
| T-15-07 | Information disclosure | friend snapshot/typing | mitigate | Check block/unfriend before Redis; generic unavailable responses avoid enumeration. |
| T-15-08 | Tampering | cursors/DTO | mitigate | Server signs/binds cursor to destination, version, rank/name/ID; reject malformed/stale cursors. |
| T-15-09 | Denial of service | typing endpoint | mitigate | Per-user/IP limits, 2-second refresh guard, 5-second TTL, bounded reads. |
| T-15-10 | Repudiation | activity events | mitigate | Server eventId, UTC timestamp, source, dedupe key, structured redacted logs. |
| T-15-SC | Tampering | package install/migration | mitigate | No package install beyond 15-01; SQL static safety assertions and locked dependency ownership. |
</table>
