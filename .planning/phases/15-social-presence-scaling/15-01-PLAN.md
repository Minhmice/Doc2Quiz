<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser to heartbeat/activity routes | Untrusted authenticated request crosses into server route and Redis writes. |
| Route to Redis | Server-controlled key/value construction crosses into external Redis. |
| Proxy headers to rate limiter | Forwarded IP is untrusted metadata and must be normalized before use. |
| Server logs/metrics | Operational output can cross into operator-visible systems. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-15-01 | Spoofing | heartbeat/activity auth | mitigate | Require `requireApiUser`; ignore unauthenticated identity claims. |
| T-15-02 | Tampering | Redis keys and session IDs | mitigate | Generate opaque IDs server-side; namespace exact keys; validate UUID/user ID format. |
| T-15-03 | Information disclosure | metrics/logs | mitigate | Redact URLs, credentials, values, tokens, session IDs, and IPs; tests assert redaction. |
| T-15-04 | Denial of service | heartbeat/limiter | mitigate | Per-user/IP fixed windows, bounded TTL/index, command timeouts, fail-closed limiter outage. |
| T-15-05 | Elevation of privilege | route identity | mitigate | Derive user ID only from authenticated server session. |
| T-15-SC | Tampering | package install | mitigate | No new package unless required; existing package lock and package legitimacy checked before install. |
</table>
</threat_model>
