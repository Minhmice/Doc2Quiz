## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser to client cache | Server DTO enters client presentation state; client code must not gain authority. |
| Realtime service to UI | Untrusted/stale payload enters invalidation handler. |
| Browser to typing/message API | User input crosses into authenticated server routes. |
| Load harness to external targets | CLI target/config crosses into Redis/SQL/browser test systems. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-15-16 | Tampering | client presence state | mitigate | Render server bucket/source; bounded cache cannot classify/filter/sort/cursor mutate. |
| T-15-17 | Spoofing | realtime invalidation | mitigate | Ignore payload display fields; reconcile via authenticated HTTP scoped to current user/conversation. |
| T-15-18 | Information disclosure | realtime/load evidence | mitigate | Event metadata excludes bodies/raw values/tokens/IPs; schema redaction rejects secrets. |
| T-15-19 | Denial of service | heartbeat lifecycle | mitigate | One AppShell controller, cadence jitter, visibility pause, bounded cache and request abort. |
| T-15-20 | Tampering | load target config | mitigate | Explicit disposable confirmations, allowlist, production/shared URL refusal. |
| T-15-SC | Tampering | package/script execution | mitigate | No package install; script uses Node stdlib and validates all external config. |
