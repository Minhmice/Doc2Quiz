# Doc2Quiz — TikTok Slang Dictionary 2024–2026

> English terms first, Vietnamese terms later. Definitions describe internet usage, not formal dictionary meanings.

## Usage labels

- **Khen:** safe for success states.
- **Cà khịa:** optional reactions only; never shame users.
- **Brainrot:** easter eggs or rotating loading copy only.
- **Thô:** disabled by default; unsuitable for school/minor deployments.
- Keep primary buttons, errors, privacy, account recovery, destructive actions and accessibility instructions literal.

## Recommended density

| Surface | Slang density | Example |
|---|---:|---|
| Primary CTA | 0–10% | `Start quiz` |
| Secondary CTA | 20–30% | `Run it back` |
| Loading rotation | 40–60% | `Let it cook` |
| Correct reaction | 30–50% | `You ate` |
| Wrong reaction | 15–30% | `Minor fumble` |
| Empty state | 30–50% | `No lore found` |
| Error / destructive | 0% | `Upload failed. Try again.` |
| Easter egg | 80–100% | `6-7 questions left` |

## Cultural note

Many terms existed before TikTok and were amplified there. Some came through AAVE, Black internet culture, ballroom/LGBTQ+ language, gaming, music or fandoms. Use them as contemporary internet language, not as caricatures of those communities.
